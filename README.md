# Thesis #49: Pre-Metastatic Niche Formation as a Graph-Reachability Problem

**Author:** Kelechi Emeka Ogbonna  
**Affiliation:** Independent computational research / Project Confluence  
**Date:** September 2026

## Overview

This repository contains **Thesis #49** of the computational oncology series. It extends prior work in Thesis T05 (metastasis on anatomical graphs) and Thesis T06 (sparse connectome controllers) by formalizing the biological phenomenon of the pre-metastatic niche (PMN) as a graph-reachability and controllability problem.

While biological literature (e.g., Kaplan et al., 2005; Peinado et al., 2012) has established that primary tumours secrete exosomes and cytokines to remodel distant organs before metastatic dissemination, this work quantifies this process using a directed weighted anatomical graph. Nodes undergo a 3-state transition (non-permissive -> primed -> permissive) driven by exosome flux, and the impact of primary tumour resection timing is evaluated as a window of controllability.
